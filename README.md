## Основные понятия

| Термин | Описание |
| :--- | :--- |
| **ЖСС** | Жилищно-строительный сберегательный счёт — специальный счёт для накопления средств на покупку жилья |
| **Отбасы Банк** | Единственный банк в РК, реализующий систему ЖСС |
| **Депозит** | Накопительный счёт «Баспана» для целевого сбора средств на жильё |
| **Оценочный показатель (ОП)** | Коэффициент финансовой дисциплины вкладчика. Чем выше — тем ниже ставка по займу |
| **Договорная сумма (ДС)** | Полная стоимость жилья, которое планируешь купить. База для всех расчётов |
| **Премия государства** | Ежегодная выплата из бюджета — 20% от суммы пополнений, но не более чем с 200 МРП |
| **МРП 2026** | 4 325 тенге (утверждён Законом РК № 239-VIII от 08.12.2025) |

## Флоу получения ипотеки

Полный путь от нуля до ключей. Три маршрута — в зависимости от того, сколько у тебя есть сейчас.

```
┌─────────────────────────────────────────────────────────────────┐
│                        СТАРТ                                    │
│              Открыть депозит «Баспана» в Отбасы банке           │
│              (нужен только паспорт, 15 минут, бесплатно)        │
└────────────────────────┬────────────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────────────────┐
│              Определить договорную сумму (ДС)                   │
│         ДС = цена квартиры + 10–15% на рост рынка               │
└────────────────────────┬────────────────────────────────────────┘
                         │
          ┌──────────────┼───────────────────────┐
          │              │                       │
          ▼              ▼                       ▼
   [Нет денег]    [Есть 50% сразу]      [Подходишь под
    Копить         Промежуточный          гос. программу]
    3+ лет              заём              Предварительный
                                              заём
```

### Маршрут А — Жилищный заём (накопление 3+ лет)

```
Шаг 1  →  Открыть депозит «Баспана»│
           │  Указать ДС и срок накопления
           │  Рассчитать ежемесячный взнос

Шаг 2  →  Копить ежемесячно ≥ 3 года
           │  Пополнять ≥ 865 000 ₸/год → получать госпремию 173 000 ₸/год
           │  Досрочные взносы повышают ОП
           │  Можно пополнять пенсионными из ЕНПФ

Шаг 3  →  Достичь ОП ≥ 16 + накопить 50% от ДС
           │  Обычно это совпадает по времени при дисциплинированных взносах

Шаг 4  →  Пройти оценку платёжеспособности
           │  Доход за 6 мес. · справки · кредитная история
           │  Сертификат — за 15 минут

Шаг 5  →  Выбрать жильё
           │  Первичный / вторичный рынок
           │  Через Baspana Market или самостоятельно

Шаг 6  →  Подать заявку на жилищный заём
           │  Онлайн или в отделении
           │  Банк проверяет документы до 3 рабочих дней

Шаг 7  →  Подписать договор (ЭЦП)
           │  Нотариус · залог · регистрация в ЦОН / eGov

Финиш  →  Вы собственник! Ставка 3,5–5%, платёж ~ 99 000 ₸/мес
```

---

### Маршрут Б — Промежуточный заём (есть 50% прямо сейчас)

```
Шаг 1  →  Открыть депозит, внести 50% от ДС единовременно

Шаг 2  →  Ждать ~6 месяцев
           │  За это время ОП вырастает до 5
           │  На депозит начисляется 2% + госпремия

Шаг 3  →  Подать заявку на промежуточный заём при ОП ≥ 5
           │  Банк выдаёт 100% стоимости жилья
           │  Ставка: 8,5% (при ОП = 5)

Шаг 4  →  Платить проценты 3 года
           │  50% лежат на депозите, продолжают расти
           │  ОП растёт — ставка может снизиться

Шаг 5  →  Через 3 года → автоматический переход на жилищный заём
           │  Депозит гасит половину долга
           │  Ставка падает до 3,5–5%

Финиш  →  Продолжаешь платить по жилищному займу до полного погашения
```

---

### Маршрут В — Предварительный заём / к примеру «Наурыз» (минимальный взнос)

```
Шаг 1  →  Открыть депозит, внести ≥ 2 млн ₸ (мин. для «Наурыз»)
           │  Проверить: нет ли жилья за последние 5 лет

Шаг 2  →  Подать заявку через Baspana Market
           │  Онлайн с компьютера · выбрать «Наурыз» · ЭЦП
           │  Банк проверяет статус жилья до 3 рабочих дней

Шаг 3  →  Пройти отбор (конкурс по накоплениям)
           │  Приоритет — у кого больше накоплено на депозите
           │  Прием заявок — раз в год (обычно март)

Шаг 4  →  Получить предварительный заём
           │  Ставка 7% (соц. категории) / 9% (остальные)
           │  Первый взнос 10% (чистовая) / 20% (черновая)

Шаг 5  →  Параллельно копить на депозите до 50%
           │  Когда накопится 50% → переход на жилищный заём 3,5–5%

Финиш  →  Жильё получено. Платишь по жилищному займу
```

---

### ⚠️ Универсальные стоп-факторы (актуальны для всех маршрутов)

| Риск | Что происходит |
|---|---|
| Пропуск платежей по депозиту | ОП снижается → хуже ставка по займу |
| Закрытие депозита раньше 3 лет | Госпремия возвращается в бюджет |
| Другие кредиты / высокая нагрузка | Снижается оценка платёжеспособности |
| ОП = 0 при подаче на промзаём | Отказ (с февраля 2024, минимум — ОП 5) |
| Нецелевое использование займа | Госпремия возвращается в бюджет |
| Пенсионные → только осн. долг | С 31.01.2026 ЕПВ нельзя тратить на проценты |

## Дополнительные плюшки

Помимо базовой схемы, у Отбасы банка есть ряд инструментов, которые позволяют копить быстрее и платить меньше налогов.

---

### 1. Семейный пакет — множим госпремию на количество членов семьи

Если открыть депозиты на всех членов семьи, государственная премия начисляется на каждый депозит «Семейного пакета». Перед получением займа депозиты можно объединить в один вклад и получить общий жилищный заём, сохранив премии всех членов семьи.

**Кто входит:** супруг/а, родители, дети, братья и сёстры.

```
Пример: семья из 4 человек (ты + супруга + отец + мать)
→ 4 депозита × 173 000 ₸ госпремии = 692 000 ₸ / год
→ за 3 года: 2 076 000 ₸ только от государства
```

> ✅ Один из самых мощных лайфхаков. Открываешь депозиты на всю семью → каждый получает госпремию → перед займом объединяешь всё в один вклад.

---

### 2. Детский депозит — жильё для ребёнка с первых дней жизни

В Отбасы банке можно открыть персональный депозит на ребёнка с первых дней его жизни. На него начисляется вознаграждение банка 2% и премия государства в размере 20% от суммы накоплений за год (максимально на 200 МРП). При достижении 3-летнего срока накопления, половины договорной суммы и необходимого уровня ОП он даёт право на получение кредита по ставке 5% и ниже — если владельцу депозита исполнилось 18 лет.

| Параметр | Значение |
|---|---|
| Открыть можно | С первого дня жизни |
| С 14 лет | Ребёнок сам управляет с согласия родителей |
| Вхождение в Семейный пакет | ✅ Да |
| Ставка займа в 18+ лет | от 5% |

---

### 3. Депозит «Арнау» — самая низкая ставка в стране для детей

Депозит «Арнау» открывается на ребёнка на срок минимум 10 лет. По достижении ребёнком 18 лет он даёт право на жилищный заём по самой низкой ставке — даже при невысоком доходе.

| Параметр | Значение |
|---|---|
| Срок накопления | 10–15 лет |
| Ставка вознаграждения | 2% годовых |
| Госпремия | 20% (до 200 МРП/год) |
| Ставка займа | 2% (самая низкая в системе) |
| Вхождение в Семейный пакет | ❌ Нельзя |
| Переход с других программ | ❌ Нельзя |

> ⚠️ Нельзя делить, уступать и объединять. Подходит тем, кто готов копить 10+ лет целенаправленно.

---

### 4. «Жас Отбасы» — льгота для молодожёнов

Если вы недавно вступили в брак, можно получить промежуточный заём всего под 6% годовых при периоде накопления один год. Можно открыть депозиты на обоих супругов, объединить их в Семейный пакет и получать двойную премию государства.

| Параметр | Значение |
|---|---|
| Условие | Молодая семья (недавно зарегистрированный брак) |
| Ставка промзайма | **6%** (вместо стандартных 8,5%) |
| Срок до займа | **1 год** (вместо стандартных 3 лет) |
| Двойная госпремия | ✅ Через Семейный пакет |

> ✅ Мощная плюшка для молодых пар — ставка ниже и ждать меньше.

---

### 5. Пенсионные накопления из ЕНПФ — ускоряем накопление

Часть пенсионных накоплений из ЕНПФ сверх порога достаточности можно перевести на депозит в Отбасы банке для улучшения жилищных условий. Можно использовать как свои накопления, так и пенсионные близких родственников — родителей, детей, братьев, сестёр, дедушек, бабушек.

```
Порядок действий:
1. Проверить доступную сумму на enpf.kz или в приложении ЕНПФ
2. Открыть спецсчёт в Отбасы банке (онлайн или видеобанк)
3. Подать заявку на enpf-otbasy.kz с ЭЦП
4. ЕНПФ переводит деньги в течение 5 рабочих дней
5. Потратить на улучшение жилья в течение 20 рабочих дней
```

> ⚠️ Важное изменение с 31.01.2026: пенсионными накоплениями нельзя оплачивать проценты по ипотеке. ЕПВ можно использовать только для уменьшения основного долга. Проценты оплачиваются исключительно из личных средств заёмщика.

> ⚠️ После перевода ЕПВ на депозит ипотечный заём нужно оформить в течение 3 лет — иначе деньги вернутся в ЕНПФ.

### 6. Налоговый вычет по вознаграждению — возврат ИПН

Заёмщики Отбасы банка могут применить налоговый вычет по уплаченному вознаграждению по ипотеке. Для этого нужно предоставить работодателю заявление на применение предварительного налогового вычета. Максимальный предел вычета — 118 МРП в год (в 2026 году: 118 × 4 325 = 510 350 ₸).

```
Пример (зарплата 400 000 ₸, вознаграждение по ипотеке 30 000 ₸/мес):

Без вычета:   ИПН = ~35 200 ₸/мес → 422 400 ₸/год
С вычетом:    ИПН уменьшается на вознаграждение по ипотеке
Экономия:     до ~36 000 ₸/год (зависит от суммы вознаграждения)
```

> 📌 Подай заявление работодателю — это бесплатная экономия. Нужно подтвердить в декларации 270.00 по итогам года.

## 📊 Оценочный показатель (ОП)

### Что это

ОП — индикатор финансовой дисциплины вкладчика. Чем выше ОП, тем ниже ставка по займу.

### Формула расчёта

```
ОП = (Начисленное вознаграждение ÷ Договорная сумма) × 1000
```

**Пример:** вознаграждение 300 000 ₸, ДС = 20 000 000 ₸
```
ОП = (300 000 ÷ 20 000 000) × 1000 = 15
```

### Пороги ОП и что они дают

| ОП | Что открывается | Ставка займа |
|:---:|---|:---:|
| 0 | ❌ Заём не выдадут | — |
| ≥ 5 | ✅ Промежуточный заём (≈ 6 мес. ожидания) | 8,5% → 5% |
| ≥ 16 | ✅ Жилищный заём (3+ года накопления) | 5% |
| > 16 | ✅ Жилищный заём по сниженной ставке | 3,5–5% |
| 48 | 🏆 Максимум | 3,5% |

### Как повысить ОП

- Пополнять депозит **раньше** положенного срока
- Вносить суммы **выше**, чем указано в договоре
- Продолжать копить **после 3 лет** на том же депозите

> 💡 Чем **меньше договорная сумма** — тем **быстрее растёт ОП** при том же вознаграждении. Поэтому важно точно указывать ДС, а не завышать её.

## Договорная сумма

### Определение

**Договорная сумма (ДС)** — полная стоимость жилья, которое планируешь купить. Именно от неё считаются 50% накоплений, ежемесячный взнос и оценочный показатель.

```
ДС = реальная цена квартиры
```

### Минимальный порог

```
500 МРП = 500 × 4 325 = 2 162 500 ₸ (минимум в 2026 году)
```

### Пример расчёта — квартира 30 млн ₸

| Параметр | Значение |
|---|---|
| Договорная сумма | 30 000 000 ₸ |
| Накопить (50% от ДС) | 15 000 000 ₸ |
| Срок накопления | 3 года (36 мес.) |
| Ежемесячный взнос (min) | ~417 000 ₸ |

## Государственная премия

### Как работает

Помимо вознаграждения банка **2% годовых**, раз в год вкладчик получает премию от государства.

```
Госпремия = 20% от суммы пополнений за год
Максимальная база = 200 МРП = 865 000 ₸ (2026 год)
Максимальная премия = 865 000 × 20% = 173 000 ₸ / год
```

### Важные правила

| Правило | Детали |
|---|---|
| Начисляется только на **1 депозит** | Даже при нескольких счетах — премия на один |
| Считается от **пополнений за год** | Не от остатка на счёте, а от суммы взносов за год |
| Пополнять выгоднее на **200 МРП+** | Всё сверх 200 МРП — без дополнительной премии |
| Пополнить можно **пенсионными** из ЕНПФ | Своими и родственников (супруг, родители, братья, сёстры, бабушки/дедушки) |

### Оптимальная стратегия

```
Минимум 865 000 ₸ в год = ~72 100 ₸ в месяц
→ это обеспечивает максимальную госпремию 173 000 ₸
```

> 💡 МРП растёт каждый год — вместе с ним растёт и максимальная премия. В 2025 году МРП был 3 932 ₸, потолок премии был ~158 000 ₸. В 2026 — уже 173 000 ₸.

## Формула ежемесячного платежа

Аннуитетный платёж (равные выплаты каждый месяц):

$$PM = S \times r \times \frac{(1+r)^n}{(1+r)^n - 1}$$

**Где:**
- `S` — сумма займа
- `r` — месячная ставка = годовая% ÷ 12 ÷ 100
- `n` — количество месяцев

### Пример: заём 10 млн ₸ под 3,5% на 15 лет

```
r = 0.035 ÷ 12 = 0.002917
(1 + r)^180 = 1.002917^180 ≈ 1.689
PM = 10 000 000 × 0.002917 × (1.689 ÷ 0.689) ≈ 69 500 ₸/мес
```
